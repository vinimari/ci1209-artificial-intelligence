O projeto foi estruturado utilizando a linguagem C++. A arquitetura foi dividida 
nos seguintes arquivos:

- main.cpp:
  Gerencia a conexão com o servidor Redis, o loop principal de turnos,
  o histórico de estados (para evitar repetição) e a  coordenação entre a
  leitura do tabuleiro e a chamada da IA.

- modelo.h / modelo.cpp:
  Responsável pela representação do estado do jogo.

- ia.h / ia.cpp:
  Contém a lógica do algoritmo minimax

- heuristica.h / heuristica.cpp:
  Traduz o estado do tabuleiro em um valor numérico para guiar o Minimax.

- tabuleiro.c / tabuleiro.h (Fornecidos):
  Biblioteca de comunicação com o controlador via Redis.

- makefile:
  Script de compilação que gera o executável `jogador_ia`.

A variante utilizada foi o **Minimax com Poda Alfa-Beta** e profundidade fixa.

A. Poda Alfa-Beta:
   Utilizada para reduzir o espaço de busca, cortando ramos da árvore que não
   influenciam a decisão final.

B. Otimização de Memória:
   Em vez de copiar o objeto do tabuleiro a cada nó da árvore, o algoritmo
   passa uma única referência do tabuleiro e utiliza métodos `mover()`
   e `desfazer()` para aplicar e reverter jogadas.

C. Ordenação de Movimentos:
   Para a Onça, os movimentos são ordenados priorizando capturas (saltos). Isso
   aumenta a probabilidade de encontrar bons movimentos cedo, maximizando a
   eficiência da poda Alfa-Beta.

D. Detecção de Repetição (Histórico):
   O algoritmo verifica se o estado resultante de um movimento já ocorreu
   recentemente no histórico da partida. Se sim, aplica uma penalidade severa
   na pontuação. Isso previne loops infinitos e empates por repetição.


O sistema utiliza uma função de avaliação única para ambos os jogadores. 
Fatores considerados:

1. Captura: +2000 pontos por captura de cão, incentivando a onça capturar
e os cães a sobreviverem.

2. Mobilidade da Onça: +50 por movimento disponível, evitando levar a onça para
lugares que será encurralada. Para os cães significa cercar a onça.

3. Penalidade de recuo: -100 se a onça estiver nas linhas 5-7,  forçando ela
a para o ataque
 
4. Ruído: Um pequeno valor random para desempatar jogadas com a mesma pontuação 
heurística, ajudando a evitar ciclos de repetição.

- Para executar:
   Instalar dependências:
   sudo apt update
   sudo apt install libhiredis-dev libreadline-dev
   sudo apt install redis-server

   Iniciar o servidor Redis:
  `redis-server redis.conf`

   Compilar o código:
  `make all`
  `./controlador o 100 0`
  `./jogador_ia <animal>` ('o' para onça, 'c' para cão)
